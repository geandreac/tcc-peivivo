## O que me preocupa
1. **O mock ainda modela a coordenação como vínculo por estudante.** O banco v3 já a trata como membro da escola. A divergência está documentada e só some com o `supabaseApi` (R2/R3.5).
2. **Captura de página inteira com barra fixa** mostra a barra no meio da imagem. É um artefato da ferramenta, não da tela. Para o artigo, usar as capturas de viewport ou recortar.
3. **Fonte de leitura facilitada** depende do que o dispositivo tem instalado (Verdana na maioria dos sistemas; Atkinson Hyperlegible se houver). Não carregamos web font por causa do orçamento de desempenho; se a banca pedir uma fonte específica para dislexia, é uma decisão de produto (custo de ~40 kB).
