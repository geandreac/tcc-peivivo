# Links do projeto

- **Repositório GitHub:** https://github.com/geandreac/tcc-peivivo
- **Site publicado na Vercel:** https://tcc-peivivo.vercel.app

PEI Vivo — plataforma colaborativa entre escola, família e equipe de saúde para
adaptação personalizada de materiais didáticos para estudantes com TEA, TDAH e
dislexia (TCC de Sistemas de Informação, CEUNI FAMETRO).

O site publicado é o protótipo da branch `main`, com dados fictícios de demonstração.
